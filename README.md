# 🛠️ Sistema de Gestión de Equipos - Gestión Integral

Bienvenido al repositorio oficial del **Sistema de Gestión de Equipos**. Este sistema permite el control total de inventario, mantenimientos, licencias y copias de seguridad de forma centralizada.

## 🚀 Despliegue Rápido
Este repositorio está configurado para ejecutarse en **AWS EC2** con **Nginx** y **PM2**.

Para actualizar el servidor con los últimos cambios de la rama `main`, simplemente ejecuta:
```bash
./actualizar.sh
```
